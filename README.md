# 闲置星球 · Idle Planet

公司内部闲置物品循环平台。员工在一个网页里发布闲置、搜索发现、提交申请、卖家选人、线下交接、双方确认完成——把散落在群聊里的闲置信息变成可搜索、可追踪、有明确交易状态的内部集市。平台不收款、不托管、不配送。

## 功能

- **交易闭环**：发布（一口价 / 免费赠送）→ 搜索筛选 → 申请 → 卖家选人锁定 → 交付 → 买家确认完成；完整状态机与并发安全（条件更新 + 唯一索引双保险）
- **券·权益**：无实物券类商品（图片选填、有效期、数量拆分成组、过期自动下架、集市折叠「剩 N 张」）
- **心愿墙**：求购心愿公开墙（星空便签 UI），小星双向异步撮合（新货找心愿 / 新心愿找货），邀请、续期、实现闭环
- **AI 助手「小星」**（智谱 GLM，OpenAI 兼容协议）：
  - 传图或一句话自动生成商品草稿（标题/描述/分类/成色/推荐挂牌价/全新参考价/缺失提示/风控预检）
  - 批量发布（清仓模式）：多张照片并发识别，生成草稿表格逐张可改、一次发布
  - 语义搜索兜底：关键词搜不到时按自然语言理解匹配在售商品
  - 问问小星：买家对商品提问，AI 依据商品信息作答（只给提问者，卖家看匿名问题列表）
  - 小星代谈：买卖双方 AI 代理在各自底线内议价（底价/心理价互不可见），人做最后确认
  - 价值报告 / 心愿助手：看板数据生成运营总结；口语心愿整理成规范文本
- **风控预检**：公司资产标签、违规品识别——强提醒 + 发布者确认 + 管理员复核，不自动拦截
- **治理与度量**：管理后台（商品/白名单/分类/未确认交易）、价值看板（双口径：剔除或包含演示数据）、闲置英雄榜（买卖/部门三榜，永远剔除演示账号）
- **白名单登录**：工号校验（验证期简化），会话 14 天；预留飞书扫码绑定结构

## 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Node 24（原生 TS 执行，无构建）+ Hono + Zod + `node:sqlite`（零原生依赖） |
| 前端 | React 19 + Vite + antd 6 + TanStack Query + Recharts |
| AI | 智谱 GLM（OpenAI 兼容 chat/completions），提示词配置在 `prompts/*.txt`，mtime 热加载 |
| 测试 | `node:test`（150+ 用例：状态机/并发/隐私断言/AI 降级） |

## 快速开始

```bash
npm install
npm run build                # 前端构建到 web/dist，由后端托管
npm run seed:demo            # 可选：演示账号与演示商品（库非空时拒绝执行）
npm start                    # 默认 http://localhost:3000
```

演示账号：管理员 `A001 / 管理员`；员工 `E001`~`E006`（登录仅需工号）。

AI 功能配置：复制 `.env.example` 为 `.env` 填入 `AI_API_KEY`。不配置时所有 AI 入口自动隐藏，主流程不受影响。

## 部署

单进程单体：把项目目录（含 `node_modules` 与 `web/dist`）拷到 Linux 主机，装 Node 24 直接跑；`data/` 目录（SQLite + 图片）放持久化磁盘并定期备份。也可用 pm2 / systemd 托管该进程。环境变量见 `.env.example`。

## 目录

```
server/   后端（Hono 路由 / services 状态机 / node:sqlite）
web/      前端（React SPA）
shared/   前后端共用 Zod schema 与类型
prompts/  小星提示词（纯文本，热加载，可自行调优）
```
